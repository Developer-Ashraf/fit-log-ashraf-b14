# 🏋️‍♂️ FitLog — Dark Gym Companion & Workout Tracker

FitLog is a modern, responsive web application designed for fitness enthusiasts to browse exercises, structure daily workout plans, and track workout statistics in real-time.

## 🚀 Live Demo
- **URL:** [https://fit-log-ashraf-b14.vercel.app/]

## 🛠️ Technologies Used
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Toast Notifications:** React Hot Toast
- **State Management:** React Context API + LocalStorage Persistence

## ⭐️ Key Features
1. **Interactive Workout Library:** Explore major lifts categorized by muscle group with real-time search filtering and sorting options (Duration, Calories, Rating).
2. **Dynamic Plan & Saved Management:** Add up to 5 lifts per day with duplicate validations and live-updating Navbar badges.
3. **Live Workout Metrics:** Dynamic calculation of total exercises, estimated duration, and burned calories.
4. **Completion Tracking:** Mark exercises as done with interactive UI status updates.
5. **Persistent Data:** State persists across reloads utilizing Browser LocalStorage.
